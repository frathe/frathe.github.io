# frathe.github.io

PicFetch's public site. GitHub Pages publishes the `docs/` directory on `main` at https://frathe.github.io/.

The pages are generated on the `website` branch of [frathe/picfetch](https://github.com/frathe/picfetch). Copy that branch's `docs/` tree here after `make build` and `make check`, and keep `docs/robots.txt` and `docs/.nojekyll`.

Former `/picfetch/` URLs redirect to this root site.
